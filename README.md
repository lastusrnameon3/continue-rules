# continue-rules

Continue AI coding assistant rules, personas, and deployment standards for infrastructure engineering.

## Add to a Project

```bash
git subtree add \
  --prefix .continue/rules \
  git@github.com:lastusrnameon3/continue-rules.git \
  main --squash
```

## Pull Updates

```bash
git subtree pull \
  --prefix .continue/rules \
  git@github.com:lastusrnameon3/continue-rules.git \
  main --squash
```
